# Install this GitHub profile README

## 1. Create the special profile repository

Create a **public** GitHub repository named exactly:

```text
adarsh-pathak-2006
```

GitHub recognizes a public repository that matches your username as your profile README.

## 2. Upload the package

Upload everything inside this folder to the repository root, preserving the structure:

```text
README.md
assets/
resume/
.github/workflows/snake.yml
```

Commit to the `main` branch.

## 3. Enable the contribution animation

1. Open the repository's **Settings**.
2. Go to **Actions → General**.
3. Under **Workflow permissions**, select **Read and write permissions**.
4. Save.
5. Open **Actions → Generate contribution snake → Run workflow**.

The animation will appear after the workflow creates the `output` branch. It then refreshes daily.

## 4. Pin the best repositories

On your GitHub profile, pin these repositories in this order:

1. `where_is_my_train_backend`
2. `AI--Interview-System`
3. `Tic-Tac-Toe-Multiplayer`
4. `Ekokintsugi-Website`

Use the remaining pinned slots for projects that show a different engineering strength.

## 5. Make the profile recruiter-ready

- Keep the bio concise: `Backend-focused software engineer building real-time and AI-enabled products.`
- Set location to `Varanasi, India`.
- Add a professional profile photo.
- Add a LinkedIn badge only after the LinkedIn profile is complete and current.
- Keep live demos working and repository descriptions specific.
- Add screenshots, setup instructions, architecture notes, and `.env.example` to every featured project.

## Notes

- GitHub profile READMEs do not run JavaScript. The included animation uses a safe SVG and a GitHub Action.
- Stats cards are generated by public README services. If one becomes unavailable, remove only that `<img>` block; the rest of the profile remains intact.
- Update the résumé PDF in `resume/` whenever the résumé changes.
